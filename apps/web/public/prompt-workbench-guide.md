# מרווח — חבילת עבודה לפרומפטים ולהקשר

כאן אפשר לעבוד ישירות על הוראות העוזר, בנפרד מספר ההפעלה. החבילה מכילה שני מסמכים עם תפקיד שונה:

- **PROMPTS.md — המקור הפעיל לעריכת הפרומפטים.** כולל את התפקיד, אופן השיחה, כללי המקורות, חמשת התוצרים, האינטייק, הדוגמאות, בקרת הבקשה וחוזי הפלט. לאחר עריכה מסנכרנים את המקור, בודקים ובונים מחדש את האתר.
- **CONTEXT.md — ניהול ההקשר.** מסביר מה נכנס לבקשה, מאיזה תיק ופגישה, מה קודם למה, ואילו חלקים נאכפים בקוד. אפשר לערוך אותו כמסמך עבודה; שינוי מדיניות סינון, זמן או הרשאות דורש גם שינוי קוד ובדיקות.

## איך עורכים פרומפט

1. פותחים את PROMPTS.md ועורכים את הסעיף המתאים. עדיף שינוי ממוקד עם דוגמה בדיונית קצרה של תגובה רצויה ולא רצויה.
2. משאירים את סימני BEGIN/END ואת שמות המשתנים בדיוק כפי שהם. אלה מאפשרים לבונה לזהות כל חלק ולשלב בו את פרטי ההפעלה.
3. מעדכנים את גרסת ההוראות כאשר משנים התנהגות.
4. מריצים משורש הפרויקט:

```sh
npm run prompts:sync
npm run prompts:check
npm test
npm run typecheck
npm run prompt-workbench
npm run handbook
npm run build
```

5. בודקים בדפדפן על דוגמה בדיונית: שאלה ראשונה, תשובה קצרה, חוסר מידע, בקשת סיום, יצירת טיוטה והצעת עדכון. שינוי שעבר בדיקות קוד עדיין יכול להפיק ניסוח לא מוצלח במודל.
6. מפרסמים את הקוד, קובץ ההוראות שנוצר, חבילת העבודה וספר ההפעלה יחד. האתר הפעיל אינו משתנה רק משום שנערך קובץ מקומי או הורד עותק מהאתר.

`prompts:sync` יוצר את `packages/prompts/authored.generated.ts`. אין לערוך את הקובץ שנוצר ישירות. `prompts:check` בודק שהמקור והקובץ הפעיל תואמים ואינו משנה קבצים. הבנייה נעצרת אם יש ביניהם פער.

## מה אפשר לשנות בקלות

הטון, רמת הפירוט, האופן שבו שאלה נשענת על מה שנכתב, נוסח הסיכום, תיאור העדכונים ודוגמאות ההתנהגות נמצאים בהוראות. למשל, אפשר לחזק העדפה לשאלת השלמה קצרה על פרט חסר שכבר עלה בשיתוף, בלי להפוך כל פגישה לרשימת שאלות.

## מה אינו רק שינוי פרומפט

מכסת השאלות, אימות מקורות, מבנה הנתונים, בידוד תיקים וענפים, בדיקת גרסאות ושמירה בשרת נאכפים גם בקוד. שינוי טקסט שמבקש לעבור מגבלה כזו לא ישנה אותה. חוזי הפלט מופיעים בהוראות כדי שהמודל ידע מה להחזיר, אך חייבים להישאר תואמים ל־`apps/api/validation.ts` ול־`packages/contracts/index.ts`.

## דוגמאות ההפעלה המצורפות

האתר מציע גם הורדה של הוראות שיחה ושל הוראות טיוטה כשהן מורכבות עם הקשר טכני ריק ובדיוני. אלה תצלומי דוגמה לקריאה, לא מקור העריכה. בתור אמיתי, פרטי הבקרה ומצב ההקשר משתנים; ההוראות המדויקות של אותו תור מופיעות ב״מאחורי הקלעים״.

אין להוסיף לחבילה סיסמאות, מפתחות API או מידע של מטופלים אמיתיים.
